Elyria Systems · Public Proof Surface

Authority is checked where consequence binds.

This browser demonstrator exposes one bounded principle: permission at request time is not enough. Standing must still be valid at the exact boundary where an action would become consequential. If standing is stale, revoked, mismatched, or the public proof chain has been mutated, the result fails closed.

Disclosure boundary: this is a public-safe demonstrator only. It does not expose the production authority evaluator, production key-management architecture, private signing infrastructure, private standing-token format, private corridor implementation, protected runtime law, customer policy, or commercial deployment architecture.
